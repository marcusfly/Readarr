# Claude Project Instructions

Read and follow `AGENTS.md` before making changes.

The project diary in `AGENT_LOG.md` is mandatory for coordination with Codex and
human contributors. Add a `START` entry before editing and a `HANDOFF` or `DONE`
entry before yielding. Preserve all existing uncommitted work.

Backlog state is maintained only in GitHub project items. Use `BACKLOG.md` for
GH task-access instructions and read task details directly from GitHub.
